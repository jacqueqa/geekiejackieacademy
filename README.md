## Português

### O que é a academia?

Você acaba de ser contratado como estagiário de tecnologia na lojinha de tarot da **Bruxa Maria**. A loja cresceu, os pedidos não param, e a **Geekie Jackie**, a Guardiã do Código, vai ser a sua mentora.

Aqui você aprende tecnologia **resolvendo problemas da lojinha**: produtos sem estoque, cupons vencidos, um bug no frete, um pedido que sumiu. Cada exercício conta uma situação, explica o que você precisa saber e propõe um desafio que o próprio site corrige na hora.

Funciona direto no navegador, no computador ou no celular, sem nada para instalar. Está em português e em inglês.

### Como começar

1. **Abra a academia** pelo link lá em cima.
2. **Monte o seu crachá:** escreva o seu nome e escolha um avatar.
3. **Leia o guia "Como funciona a academia"**, o primeiro cartão da página inicial. Ele tem a carta de boas-vindas e as regras do jogo.
4. **Comece pela Trilha Inicial.** São 40 exercícios de lógica com caixinhas, tabelas e fluxogramas, sem escrever código. Você não precisa saber nada de programação.
5. **Escolha o seu caminho.** O ideal é fazer pelo menos 60% da Trilha Inicial antes das outras trilhas. Dá para começar antes, mas a Geekie Jackie vai perguntar se você tem certeza. 😉

### As trilhas

| Trilha | O que você aprende |
|---|---|
| 🧩 **Inicial** | Pensar como um computador: passos, decisões, repetições e como conferir se algo está certo. É a base de todas as outras |
| 🌿 **Git** | Salvar e compartilhar código como um time: commits, branches, pull requests e conflitos |
| ⚙️ **Back End** | O JavaScript que roda por trás da loja: objetos, loops, regras de negócio e 30 desafios de algoritmos |
| 🎨 **Front End** | O que a cliente vê: HTML, CSS, acessibilidade e JavaScript que monta a vitrine |
| 🔍 **QA** | Pensar e trabalhar como QA: qualidade, requisitos, técnicas de teste, bugs e automação |
| 🤖 **IA** | Entender a IA, escrever bons prompts com o método CRAFT e nunca aceitar a primeira resposta sem conferir |
| 📊 **Dados** | Ler os pedidos da loja: somar, agrupar, ler SQL e escolher o gráfico certo |

As trilhas de QA e IA estão crescendo: novos módulos chegam aos poucos.

### Como o jogo funciona

- **XP:** cada exercício resolvido vale pontos de experiência.
- **Dicas:** se travar, peça uma dica. Cada uma custa 3 XP, e são até 3 por exercício, cada vez mais diretas.
- **Solução:** depois de 2 tentativas, dá para ver a solução, mas aí o exercício vale 0 XP. Na Trilha Inicial ele também não conta para os 60%. Dá para resolver de novo sozinho para ele voltar a contar.
- **Títulos:** você sobe de título em cada trilha e na academia inteira, de Estagiário(a) até Arquimago(a).
- **Conquistas:** medalhas por terminar níveis, estudar vários dias seguidos, explorar o conteúdo e muito mais. Veja todas na página **Conquistas**, embaixo do seu XP.
- **Crachá:** na página inicial, ele mostra o seu avatar, nível, trilha atual, progresso e as últimas medalhas.

### Onde consultar

Na página inicial, em **Recursos técnicos**:

- **Regras da Loja:** todas as regras de negócio, como "frete grátis a partir de €50".
- **Catálogo de produtos:** os produtos usados nos exercícios.
- **Glossário:** palavras de programação explicadas de forma simples, com exemplos da lojinha.
- **Grimório do Git:** todos os comandos de Git numa página, com o equivalente no VS Code.
- **Princípios de design de código:** SOLID, DRY, KISS e YAGNI, para quem já está nas trilhas de código.
- **A lojinha:** uma loja online de mentira para treinar testes de verdade. Veja o [guia da loja](shop/README.md).

### O seu progresso

- O progresso fica salvo **no navegador** que você usa. Se você limpar os dados do navegador, ele some.
- Para guardar ou levar para outro computador, use **Meu trabalho (.md)**, no rodapé. Ele baixa um arquivo com o seu progresso.
- Em outro navegador, use **Importar progresso** e escolha esse arquivo para continuar de onde parou.
- O contador de visitas do rodapé usa o [GoatCounter](https://www.goatcounter.com): ele conta as visitas sem cookies e sem guardar dados pessoais.

### Para a trilha Git

Os exercícios de Git são feitos no seu computador. Você vai precisar de:

- uma conta no [GitHub](https://github.com);
- o [Git](https://git-scm.com) instalado;
- o [VS Code](https://code.visualstudio.com).

Na trilha, você faz um **fork** deste repositório (uma cópia sua, no seu GitHub) e trabalha nele. A própria trilha explica cada passo.

### Perguntas frequentes

**Preciso saber programar?** Não. A Trilha Inicial começa do zero, sem código.

**Preciso instalar alguma coisa?** Não, só para a trilha Git (veja acima).

**Errei várias vezes. E agora?** Faz parte! Peça uma dica, releia a explicação ou abra o glossário. Um bug não é o fim da jornada, é uma chance de aprender algo novo.

**Posso usar no celular?** Pode. A academia funciona em qualquer tamanho de tela.

**Encontrei um erro na academia.** Que ótimo, você já está pensando como QA! Abra uma [issue no GitHub](https://github.com/jacqueqa/geekiejackieacademy/issues) contando o que aconteceu.

### Quer contribuir?

Para criar exercícios, mudar textos ou rodar os testes automatizados, veja o [guia de contribuição](CONTRIBUTING.md).

## English

### What is the academy?

You have just been hired as a tech intern at **Bruxa Maria’s** little tarot shop. The shop has grown, the orders keep coming, and **Geekie Jackie**, the Code Guardian, will be your mentor.

Here you learn technology **by solving the shop’s problems**: products out of stock, expired coupons, a shipping bug, a missing order. Each exercise tells a situation, explains what you need to know and gives you a challenge that the site checks on the spot.

It works right in the browser, on a computer or a phone, with nothing to install. It is in English and in Portuguese.

### Getting started

1. **Open the academy** with the link at the top.
2. **Make your badge card:** type your name and choose an avatar.
3. **Read the “How the academy works” guide**, the first card on the home page. It has the welcome letter and the rules of the game.
4. **Start with the Start Track.** It has 40 logic exercises with boxes, tables and flowcharts, and no code to write. You don’t need to know anything about programming.
5. **Choose your path.** The ideal is to complete at least 60% of the Start Track before the other tracks. You can start earlier, but Geekie Jackie will ask if you are sure. 😉

### The tracks

| Track | What you learn |
|---|---|
| 🧩 **Start** | Thinking like a computer: steps, decisions, repetition and how to check that something is right. It is the base of all the others |
| 🌿 **Git** | Saving and sharing code like a team: commits, branches, pull requests and conflicts |
| ⚙️ **Back End** | The JavaScript behind the shop: objects, loops, business rules and 30 algorithm challenges |
| 🎨 **Front End** | What the customer sees: HTML, CSS, accessibility and JavaScript that builds the shop window |
| 🔍 **QA** | Thinking and working as a QA: quality, requirements, test techniques, bugs and automation |
| 🤖 **AI** | Understanding AI, writing good prompts with the CRAFT method and never accepting the first answer without checking it |
| 📊 **Data** | Reading the shop’s orders: summing, grouping, reading SQL and choosing the right chart |

The QA and AI tracks are growing: new modules arrive little by little.

### How the game works

- **XP:** every exercise you solve gives you experience points.
- **Hints:** if you get stuck, ask for a hint. Each costs 3 XP, and there are up to 3 per exercise, more direct each time.
- **Solution:** after 2 attempts you can see the solution, but the exercise then gives 0 XP. In the Start Track it also doesn’t count toward the 60%. You can solve it again on your own to make it count.
- **Titles:** you go up in title in each track and in the whole academy, from Intern to Archmage.
- **Achievements:** badges for finishing levels, studying several days in a row, exploring the content and much more. See them all on the **Achievements** page, under your XP.
- **Badge card:** on the home page, it shows your avatar, level, current track, progress and latest badges.

### Where to look things up

On the home page, under **Technical resources**:

- **Shop Rulebook:** every business rule, like “free shipping from €50”.
- **Product catalog:** the products used in the exercises.
- **Glossary:** programming words explained simply, with examples from the shop.
- **Git grimoire:** every Git command on one page, with its VS Code equivalent.
- **Code design principles:** SOLID, DRY, KISS and YAGNI, for those already on the code tracks.
- **The shop:** a mock online shop to practise real testing. See the [shop guide](shop/README.md).

### Your progress

- Progress is saved **in the browser** you use. If you clear the browser’s data, it is gone.
- To keep it or take it to another computer, use **My work (.md)** in the footer. It downloads a file with your progress.
- In another browser, use **Import progress** and choose that file to continue where you left off.
- The visit counter in the footer uses [GoatCounter](https://www.goatcounter.com): it counts visits with no cookies and without keeping personal data.

### For the Git track

The Git exercises are done on your own computer. You will need:

- a [GitHub](https://github.com) account;
- [Git](https://git-scm.com) installed;
- [VS Code](https://code.visualstudio.com).

In the track you **fork** this repository (your own copy, on your GitHub) and work on it. The track explains every step.

### FAQ

**Do I need to know how to code?** No. The Start Track begins from zero, with no code.

**Do I need to install anything?** No, only for the Git track (see above).

**I got it wrong many times. Now what?** That’s part of it! Ask for a hint, read the explanation again or open the glossary. A bug isn’t the end of the journey, it’s a chance to learn something new.

**Can I use it on my phone?** Yes. The academy works on any screen size.

**I found a mistake in the academy.** Great, you are already thinking like a QA! Open an [issue on GitHub](https://github.com/jacqueqa/geekiejackieacademy/issues) telling what happened.
